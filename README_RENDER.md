# GyanTech Blog Advanced v1

Upload these files to the ROOT of the GitHub repo:
package.json, server.js, index.html, articles.html, article.html, admin.html.

Render: Build `npm install`; Start `npm start`. Keep the existing environment variables unchanged.

The server automatically upgrades the existing `articles` table with slug, excerpt, category, tags, image_url, status, featured, views and updated_at columns.

Routes: `/`, `/articles`, `/article/<slug>`, `/admin`.
